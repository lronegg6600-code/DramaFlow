# Release Defect Matrix

## Decision Rule

- `release_blocker=yes` means the issue must be closed before production.
- `can_ship_to_staging=yes` means the issue can be carried into staging only if the matching smoke and watchlist checks are active.
- `can_ship_to_production=yes` means the issue is accepted risk after mitigation.
