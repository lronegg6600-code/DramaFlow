# GitHub Project Setup Guide

## 需要先建什么
- 一个 GitHub Project v2：`DramaFlow Release Blockers`
- 两个 milestone：`staging-unblock`、`production-readiness`
- 一组 blocker labels

## Project 字段
- Status
- Blocker Category
- Provider Role
- SLA Level
- Blocks Staging
- Blocks Production
- Due Bucket
- Verification State

## 状态列
- Not Created
- Created
- Assigned
- Awaiting Reply
- Replied Invalid
- Verified
- Closed
- Escalated

## 使用方式
- Daily standup 看 `Daily Unblock`
- Weekly escalation 看 `Weekly Escalation`
- staging gate 看 `Blocks Staging = yes`
